# LiveHime macOS 计划书 / Roadmap

更新：2026-09-24（v0.2.7 发布时）。

## 路线 / Direction

v0.2 起放弃“原生宿主 + 隐藏 OBS 后台”的 v0.1.x 结构，改为 **OBS Studio 分支 + 树内
直播姬插件**：OBS 的场景、来源、滤镜、录制原样保留，直播姬的账号、开播、弹幕和直播间
管理放在右侧“直播姬”停靠面板里。源码补丁见 [`obs-fork/`](../obs-fork/)。

功能按 P0 → P1 → P2 推进，每一步先做完整、验证通过再往下走。

## 下一步 / Next

### 1. 语音字幕 / Live captions（已调研，待开工）

把主播麦克风和/或电脑声音实时转成字幕，烧进直播画面。

**调研结论。** 本机测试时 macOS 27 上 `zh-CN`、`zh-TW` 模型已经装好，也支持 `zh-HK`、`yue-CN`。

| 方案 | 结论 |
|---|---|
| [royshil/obs-localvocal](https://github.com/royshil/obs-localvocal)（★1.6k，GPL-2.0，Whisper） | 最成熟，但安装包约 110 MB，另需下载几百 MB 模型；中文要 small/medium 模型才准；静音时容易编出不存在的句子。可作为用户自装的备选，不集成 |
| [ratwithacompiler/OBS-captions-plugin](https://github.com/ratwithacompiler/OBS-captions-plugin)（Google 语音接口，CEA-608） | B 站播放器不显示 608 隐藏字幕，国内也连不上 Google，不采用 |
| **Apple SpeechAnalyzer / SpeechTranscriber**（macOS 26+） | **采用。** 系统自带，本机识别，不联网、不增加体积；有实时修正的临时结果，延迟低；可以直接放进现有 Swift core |

**设计。**
- 音频：通过 `obs_source_add_audio_capture_callback` 监听所选 OBS 音频源（麦克风 / 桌面音频 / 两者）。每一路单独识别，可以加说话人标签（主播 / 电脑）。
- 输出：新增“直播姬字幕”画面来源，样式和“直播姬弹幕”一致（字体、描边、背景、行数、停留时间）。停靠面板和悬浮聊天里也同步显示，方便主播核对。
- 版本：只在 macOS 26 以上提供，低版本隐藏入口。
- 注意：开了监听时，主播的声音可能混进桌面音频，被识别两次；检测到时提示用户。

**分步。**
1. ✅ 麦克风 → 中文字幕 → 字幕来源（v0.2.6）：可选任意 OBS 音频源，支持普通话、国语、粤语、English；
   “直播姬字幕”自绘，画面位置 / 框大小 / 对齐 / 描边 / 底板可调，拖边框不拉伸文字；同音词修正（直播机 → 直播姬）。
2. 两路同时（麦克风 + 桌面音频，带说话人标签）、监听串音提示。
3. （可选）导出 SRT 供录播使用；用 Apple Translation 在本机翻译成双语字幕；复用屏蔽词过滤字幕。

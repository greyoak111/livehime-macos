# LiveHime macOS

**在 Mac 上用哔哩哔哩直播姬的方式开播。** 从 v0.2.0 起，这是一个带“直播姬”面板的
OBS Studio：OBS 怎么用它就怎么用，登录、开播、弹幕和直播间管理都在右侧面板里。

> LiveHime macOS 是第三方社区项目，不是哔哩哔哩、OBS Project 或 Windows 版直播姬的官方产品，
> 也不代表它们的立场。本项目仅供学习、研究和社区交流，不提供商业服务。平台的开播资格、实名 / 人脸认证和
> 风控规则可能随时变化；应用不会自动完成或绕过任何验证。使用者需要自己确认账号资格和内容是否合规，并对
> 自己的直播负责。

## 下载 / Download

到 [Releases](https://github.com/greyoak111/livehime-macos/releases) 下载最新版，打开 DMG 后把 LiveHime 拖到“应用程序”：

- Apple 芯片（M 系列）的 Mac：`LiveHimeMacApp-<版本>-arm64.dmg`
- Intel 芯片的 Mac：`LiveHimeMacApp-<版本>-x86_64.dmg`（从 v0.2.8 起提供）

不确定是哪种：点屏幕左上角  → 关于本机，“芯片”一栏写 Apple M… 的选 arm64，“处理器”一栏写 Intel 的选 x86_64。

- 要求：macOS 13 或更高版本。语音字幕需要 macOS 26 或更高版本（Intel Mac 上能否使用取决于系统是否提供本机语音识别，不支持时字幕页会提示）。
- 应用用本地证书签名，没有经过 Apple 公证。第一次打开如果被系统拦下，到
  **系统设置 → 隐私与安全性**，点“仍要打开”。
- 第一次开播前，按提示授予屏幕录制、麦克风和摄像头权限。授权后如果提示重新打开应用，照做即可。
- 从 v0.1.x 升级前请先看 [升级说明](docs/UPGRADING.md)：登录通常会自动沿用，但场景要重新搭建。

## 功能 / Features

| | |
|---|---|
| **登录** | 用哔哩哔哩 App 扫码登录，也可以通过官方页面用密码或短信登录；登录信息存在钥匙串，自动续期；退出登录时会在服务器端注销 |
| **开播** | 选好分区后一键开播，推流地址自动填入；OBS 自带的“开始直播”按钮也走同一流程；结束直播会同时关闭直播间 |
| **人脸认证** | 开播要求认证时弹出二维码，用手机扫码完成 |
| **弹幕** | 实时显示弹幕、礼物、醒目留言（置顶）、上舰和进场；可以发弹幕，右键（或双击）回复某位观众（@TA），右键复制或禁言，管理屏蔽词、只看礼物 |
| **悬浮聊天** | 可拖动的弹幕窗口，支持置顶（其他应用全屏时也在最上面）、钉住、调不透明度（50–100%），可选是否出现在直播画面里，支持快捷键 |
| **直播间** | 修改标题、更换封面（B 站官方封面编辑器）、查看看过人数 / 点赞 / 高能数据 |
| **语音字幕** | 把麦克风（或任意音频来源）实时转成字幕，支持普通话、国语、粤语、English；只在本机识别，不上传音频（需要 macOS 26 或更高版本）。录制或直播时可以同时保存 SRT 字幕文件，时间和录像对齐 |
| **字幕来源** | 在“来源”里添加“直播姬字幕”：默认一行、底部居中；字体、描边、底板可调 |
| **更新** | 自动检查并下载新版本、退出时安装（也可以改成手动，走同一个下载通道）；可选参与测试版；可以跳过某个版本或回退到上一版本，安装前自动备份场景和设置。下载的安装包要通过校验值和签名证书检查才会安装 |
| **接口巡检** | “更新”页的“B 站接口巡检…”逐项检查 LiveHime 用到的 B 站接口（只读），出问题时可以把报告贴到 Issue |
| **弹幕来源** | 在“来源”里添加“直播姬弹幕”：竖版发言列表，最新消息在最下面，礼物、醒目留言、上舰有不同颜色 |
| **摆放** | 字幕和弹幕都可以选画面位置（底部居中、左下、右下……），直接拖边框改大小，文字不会被拉伸 |

接下来要做的（双路字幕、浏览器来源等）见 [计划书](docs/ROADMAP.md)。

## 常见问题 / FAQ

- **怎么更新：** v0.2.8 起应用会自己检查更新（“直播姬”面板 → 更新）。从 v0.2.7 或更早的版本升级，需要手动下载一次 DMG。

- **直播画面黑屏：** 到 系统设置 → 隐私与安全性 → 屏幕与系统录音，确认 LiveHime 已勾选，然后重新打开应用。
- **悬浮聊天出现在直播画面里：** 在悬浮窗的 ⋯ 菜单里关掉“允许被屏幕采集”。
- **配置在哪：** `~/Library/Application Support/LiveHime/obs-studio`，和普通 OBS 的配置互不影响。

## 从源码构建 / Build from source

应用是 OBS Studio 32.2.2 的修改版，所有改动以补丁形式放在 [`obs-fork/`](obs-fork/)，
构建步骤见 [`obs-fork/README.md`](obs-fork/README.md)。直播姬插件的 Swift 核心可以单独测试：
在打过补丁的源码里进入 `plugins/livehime/core` 运行 `swift test`。

`macos-livehime-adapter/` 是 v0.1.x 的旧实现（原生外壳 + 内置 OBS），仅作参考保留。
